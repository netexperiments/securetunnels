## Secure Tunneling Labs

Secure Tunneling Labs is an open-source laboratory environment for reproducible experiments with secure tunneling protocols.

## Documentation

Documentation site: [https://netexperiments.github.io/securetunnels/](https://netexperiments.github.io/securetunnels/)

## Required Tools

- GNS3
- Containerlab
- Docker
- Wireshark
- OpenSSL 3.5 or later for post-quantum experiments
- Linux virtual machines or containers
- Vendor images where required by specific labs

## Supported Experiments

- MACsec
- ANYsec
- WireGuard
- IPsec
- TLS
- DTLS
- SSH
- PKI
- Post-quantum and hybrid key-establishment experiments
